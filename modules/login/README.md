# ระบบบริการดิจิทัล มหาวิทยาลัยราชภัฏสงขลา (SKRU Digital Services Login)

ระบบและหน้าจอ **LOGIN** ตามต้นแบบของ **มหาวิทยาลัยราชภัฏสงขลา (มรภ.สงขลา - SKRU)** พัฒนาด้วย **Node.js (Express)** และ **HTML5 / CSS3 / JavaScript** พร้อมระบบการป้องกันความปลอดภัยแต่ละช่องรับข้อมูลตามมาตรฐาน **OWASP Top 10**

---

## 📸 คุณสมบัติเด่น (Key Features)

1. **ดีไซน์สวยงามตรงตามภาพต้นแบบ 100%**:
   - จำลองหน้าจอสมาร์ตโฟน 2 หน้าจอเคียงข้างกัน (**Dual Mockup Mode**)
     - **หน้าจอที่ 1 (Intro/Splash Screen):** ตราสัญลักษณ์ มรภ.สงขลา พร้อมริบบิ้นสีทอง-ขาว, ข้อความต้อนรับ *"ระบบบริการดิจิทัล มรภ.สงขลา"*, และปุ่ม Gradient *"เริ่มต้นใช้งาน"*
     - **หน้าจอที่ 2 (Login Form):** แท็บเลือกสถานะ 🎓 **นักศึกษา (Student)** และ 🏛️ **อาจารย์ / บุคลากร (Staff)**, ช่องกรอกรหัส/อีเมล, ช่องรหัสผ่านพร้อมปุ่มเปิด-ปิดตา, ลิงก์ลืมรหัสผ่าน, เช็คบ็อกซ์จดจำบัญชี, และปุ่ม *"เข้าสู่ระบบ"*
   - รองรับการสลับมุมมองเป็น **Single App Mode** สำหรับใช้งานจริงบนหน้าจอมือถือ
   - ระบบ Dashboard จำลองข้อมูลนักศึกษา/อาจารย์และบริการดิจิทัลหลังล็อกอินสำเร็จ

2. **ระบบการป้องกันความปลอดภัยแต่ละช่อง (Input Security & Hardening)**:
   - **ช่องรหัสนักศึกษา / อีเมล (`identifier`)**:
     - ตรวจสอบ Regex Whitelisting: รองรับรหัสนักศึกษา 9 หลัก (เช่น `674295027`) หรืออีเมล `@parichat.skru.ac.th` / `@skru.ac.th`
     - Sanitize ตัดอักขระแปลกปลอม, Null Bytes, และแท็ก HTML ป้องกัน Injection (SQLi, NoSQLi, XSS)
   - **ช่องรหัสผ่าน (`password`)**:
     - เข้ารหัสด้วย **Bcrypt** (Salt rounds = 12)
     - ป้องกัน Timing Attack ด้วย Constant-time comparison
     - จำกัดความยาว 6-128 ตัวอักษร ป้องกัน ReDoS และ DoS
   - **ระบบป้องกัน Brute-Force & Rate Limiting**:
     - จำกัดการเรียก Login API ต่อ IP
     - ระบบ **Account Lockout**: หากกรอกรหัสผ่านผิดเกิน 5 ครั้ง บัญชีจะถูกระงับชั่วคราว 15 นาที พร้อมตัวเลขนับถอยหลัง
   - **ความปลอดภัยระดับ Web Protocol**:
     - **CSRF Protection** ด้วย Double-Submit HMAC Tokens
     - ติดตั้ง HTTP Security Headers ผ่าน **Helmet** (Content Security Policy, X-Frame-Options, HSTS, nosniff)
     - จัดเก็บ Session ใน Secure `HttpOnly` Cookie ป้องกันการถูกขโมยผ่านสคริปต์

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันเซิร์ฟเวอร์
```bash
npm start
```
หรือโหมดพัฒนา (Auto-reload):
```bash
npm run dev
```

### 3. เข้าใช้งานผ่าน Web Browser
เปิดเบราว์เซอร์ไปที่:
👉 **[http://localhost:3000](http://localhost:3000)**
