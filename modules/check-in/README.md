# 🎓 Class Check-in System (ระบบเช็คชื่อเข้าเรียน)

ระบบเช็คชื่อเข้าเรียนแบบครบวงจร พัฒนาด้วย **JavaScript Full-Stack** (HTML/CSS/JS สำหรับ Frontend และ Node.js + Express สำหรับ Backend) โดยอ้างอิงและปรับแต่งตามต้นแบบ UI ที่กำหนดไว้อย่างแม่นยำ

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **หน้าจอ Mobile-First ตามแบบ UI จริง**:
   - แถบเมนูด้านบนระบุรหัสวิชาและเซกชัน (`4663235- sec 01`) และปุ่มดูประวัติ
   - ส่วน **Class Detail**: แสดงชื่อวิชา, รหัสวิชา, หน่วยกิต, เซกชัน, อาจารย์ผู้สอน, สถานะเช็คชื่อ (`No`/`Yes`), และวันเวลาสถานที่ (`TUE 08:00-12:00 Lab.คอม301`)
   - ปุ่ม **CHECK-IN CLASS**: กดเช็คชื่อได้ทันทีพร้อมระบบเสียงตอบรับ (Audio Chime) และ Progress Bar สรุปยอดเข้าเรียน
   - ส่วน **Classmate**: แสดงรายชื่อเพื่อนในห้องพร้อมสถานะเข้าเรียน และปุ่มแชทรูปกล่องข้อความสีแดง

2. **ระบบแชทสนทนากับเพื่อนร่วมห้อง (Interactive Chat)**:
   - กดที่ไอคอน 💬 ท้ายชื่อเพื่อนแต่ละคน เพื่อเปิดหน้าต่างส่งข้อความคุยแบบ Real-time

3. **แผงควบคุมอาจารย์ (Teacher Dashboard)**:
   - สลับเปิด/ปิด การรับเช็คชื่อของคาบเรียน
   - กำหนดรหัส PIN ประจำห้องเรียนเพื่อความปลอดภัย
   - รีเซ็ตคาบเรียนเพื่อเริ่มสัปดาห์ใหม่ พร้อมจัดเก็บประวัติย้อนหลังอัตโนมัติ
   - เพิ่มนักศึกษาใหม่เข้าสู่ห้องเรียน

4. **เครื่องมือเสริมเพิ่มเติม**:
   - ป๊อปอัปแสดง **QR Code** และรหัส PIN ประจำห้อง
   - หน้าต่างดูรายชื่อทั้งหมด (**See All**) พร้อมแถบค้นหาและตัวกรอง (ทั้งหมด / เช็คแล้ว / ยังไม่เช็ค)
   - หน้าต่างดูประวัติย้อนหลัง (**History Logs**) แสดงสถิติการเข้าเรียนแต่ละสัปดาห์

## 🚀 วิธีการติดตั้งและรันระบบ (How to Run)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. เริ่มต้นรันเซิร์ฟเวอร์
```bash
npm start
```
หรือรันแบบ Hot-reload ในโหมดพัฒนา:
```bash
npm run dev
```

### 3. เข้าใช้งานผ่านเบราว์เซอร์
เปิดเบราว์เซอร์ไปที่: [http://localhost:3000](http://localhost:3000)
