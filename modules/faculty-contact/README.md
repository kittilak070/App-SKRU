# 📅 ระบบส่งคำขอเข้าพบอาจารย์ (SKRU Teacher Appointment Request System)

ระบบส่งคำขอนัดหมายเข้าพบอาจารย์ พัฒนาด้วย JavaScript ทั้งส่วน Front-end (HTML/CSS/JS) และ Back-end (Node.js) ออกแบบ UI ตามต้นแบบ SKRU อย่างสวยงาม ทันสมัย รองรับทั้งจอมือถือและเดสก์ท็อป

---

## 🌟 ฟีเจอร์หลัก (Features)

### 1. หน้าสำหรับนักศึกษา / ผู้ติดต่อ (`index.html`)
- 🎨 **UI สวยงาม ตรงตามภาพตัวอย่าง**: โทนสีแดง SKRU, การ์ดโปรไฟล์อาจารย์ MR.Panukorn พร้อมสถานะ "พร้อมให้เข้าพบ 🟢", ป้ายเวลาให้คำปรึกษา
- 📝 **ฟอร์มส่งคำขอครบถ้วน**:
  - ชื่อ-นามสกุล นักศึกษา / ผู้ติดต่อ
  - รหัสนักศึกษา / เบอร์ติดต่อ
  - วันที่ต้องการเข้าพบ (มี Date Picker)
  - เวลาโดยประมาณ (มี Time Picker)
  - หัวข้อเรื่องที่ต้องการปรึกษา (Textarea)
- 🎫 **ระบบออกสลิปรหัสอ้างอิง (Ticket Ref Code)**: แสดงผลยืนยันการส่งคำขอทันที
- 🔍 **ระบบตรวจสอบสถานะคำขอ (Status Tracking)**: นักศึกษากรอกรหัสนักศึกษาเพื่อดูว่าอาจารย์ตอบรับหรือไม่อนุมัติ พร้อมอ่านโน้ตข้อความจากอาจารย์

### 2. หน้าสำหรับอาจารย์ / ผู้ดูแลระบบ (`admin.html`)
- 📊 **สถิติภาพรวม**: จำนวนคำขอทั้งหมด, รอดำเนินการ, อนุมัติแล้ว, ปฏิเสธ
- ⚙️ **สวิตช์ปรับสถานะอาจารย์**: สลับสถานะ "พร้อมให้เข้าพบ" ↔ "ติดภารกิจ/งดรับนัด" และแก้ไขเวลาให้คำปรึกษาได้แบบ Real-time
- ✅ **การตอบรับ / ปฏิเสธนัดหมาย**: อาจารย์กดอนุมัติหรือปฏิเสธ พร้อมพิมพ์ข้อความตอบกลับไปยังนักศึกษาได้ทันที
- 🔎 **ระบบค้นหาและกรองข้อมูล**: กรองตามสถานะ หรือค้นหาด้วยชื่อ/รหัสนักศึกษา

## 🚀 วิธีการติดตั้งและรันระบบ (How to Run)

### วิธีที่ 1: รันด้วย Node.js (แนะนำ)
1. เปิด Terminal หรือ PowerShell ในโฟลเดอร์โปรเจกต์:
   ```bash
   cd C:\Users\guide\.gemini\antigravity-ide\scratch\skru-appointment-system
   ```
2. รันเซิร์ฟเวอร์ด้วยคำสั่ง:
   ```bash
   node server.js
   ```
3. เปิดเว็บเบราว์เซอร์:
   - **หน้านักศึกษา**: [http://localhost:3000](http://localhost:3000)
   - **หน้าอาจารย์**: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

### วิธีที่ 2: รันผ่านไฟล์ `start.bat`
- ดับเบิ้ลคลิกไฟล์ `start.bat` ในโฟลเดอร์เพื่อเริ่มต้นเซิร์ฟเวอร์ทันที

## 📡 API Endpoints (Node.js REST API)

| Method | Endpoint | รายละเอียด |
|---|---|---|
| `GET` | `/api/teacher` | ดึงข้อมูลโปรไฟล์และสถานะความพร้อมของอาจารย์ |
| `PUT` | `/api/teacher` | อัปเดตสถานะ (ว่าง/ไม่ว่าง) หรือช่วงเวลาให้คำปรึกษา |
| `GET` | `/api/appointments` | ดึงรายการคำขอนัดหมายทั้งหมด (รองรับ query `studentId`, `status`) |
| `POST` | `/api/appointments` | ส่งคำขอนัดหมายใหม่จากนักศึกษา |
| `PATCH` | `/api/appointments/:id` | อาจารย์อัปเดตสถานะ (APPROVED / REJECTED) และใส่โน้ต |
