# SKRU Student Profile System (ระบบข้อมูลนักศึกษา SKRU CONNECT)

ระบบแสดงและจัดการข้อมูลนักศึกษาหน้าเดียว (Single Page Application) ออกแบบตามสเปก CSS (390px x 844px) จาก Figma มหาวิทยาลัยราชภัฏสงขลา (SKRU)

## เทคโนโลยีที่ใช้
- **หน้าบ้าน (Frontend)**: HTML5, CSS3 (ตำแหน่งและสไตล์ตรงตามที่ระบุ 100%), JavaScript (Vanilla JS)
- **หลังบ้าน (Backend)**: Node.js, Express.js
- **การจัดเก็บข้อมูล (Data Storage)**: JSON Database (`data/student.json`)

## โครงสร้างโปรเจกต์
```
Student Profile/
├── package.json          # ไฟล์การตั้งค่า dependencies
├── server.js             # เซิร์ฟเวอร์ Node.js (REST API & Static files)
├── data/
│   └── student.json      # ข้อมูลนักศึกษา
└── public/
    ├── index.html        # หน้าจอหลัก (390px x 844px)
    ├── style.css         # สไตล์ตาม CSS ที่กำหนด พร้อมเอฟเฟกต์ปฏิสัมพันธ์
    ├── app.js            # โค้จจัดการหน้าบ้าน เชื่อมต่อ API
    └── assets/
        └── avatar.png    # รูปถ่ายนักศึกษา
```

## วิธีการรันระบบ
1. เปิด Terminal หรือ PowerShell ในโฟลเดอร์โปรเจกต์
2. ติดตั้ง dependencies:
   ```bash
   npm install
   ```
3. สตาร์ทเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
4. เปิดเบราว์เซอร์ไปที่:
   ```
   http://localhost:3000
   ```

## ฟังก์ชันการทำงาน
1. **แสดงผลข้อมูลนักศึกษา**:
   - การ์ดที่ 1: ข้อมูลทั่วไป (รูปถ่าย, ชื่อไทย-อังกฤษ, สถานะนักศึกษา, รหัสนักศึกษา, คณะ, สาขาวิชา, ระดับการศึกษา, ชั้นปี)
   - การ์ดที่ 2: ข้อมูลส่วนตัว (วันเดือนปีเกิด, เบอร์โทรศัพท์, อีเมล, ที่อยู่, หลักสูตร, ปีที่เข้าศึกษา, สถานะ, เกรดเฉลี่ย GPA)
2. **คัดลอกรหัสนักศึกษา**: กดปุ่มไอคอนสี่เหลี่ยมซ้อนกันข้างรหัสนักศึกษาเพื่อคัดลอกลง Clipboard พร้อมแจ้งเตือน Toast
3. **แก้ไขข้อมูลส่วนตัว**: กดปุ่ม **"แก้ไข"** จะมีฟอร์ม Modal ให้แก้ไขข้อมูล เช่น เบอร์โทรศัพท์, อีเมล, ที่อยู่, GPA และจะส่งคำขอ `PUT /api/student` ไปยัง Node.js หลังบ้านเพื่อบันทึกข้อมูลอย่างถาวร
4. **กระดิ่งแจ้งเตือน**: คลิกเพื่อดูประกาศและข่าวสารจากทางมหาวิทยาลัย
