# ระบบจองหอพัก มหาวิทยาลัยราชภัฏสงขลา (SKRU Dormitory Booking System)

ระบบจองหอพักนักศึกษา มหาวิทยาลัยราชภัฏสงขลา (SKRU) พัฒนาขึ้นตรงตามดีไซน์จาก **FIGMA** โดยใช้ **JavaScript ทั้งระบบ** (HTML/CSS/Vanilla JS สำหรับ Frontend และ Node.js/Express สำหรับ Backend API)

---

## 🌟 จุดเด่นและฟีเจอร์หลัก (Features)

### 📱 1. หน้าตาอินเทอร์เฟซตามภาพ FIGMA (Exact Design Match)
- **Header แบรนด์ SKRU**: แถบสีแดง (`#ED1C24`) พร้อมโลโก้ตรามหาวิทยาลัยราชภัฏสงขลา และปุ่มเมนู Navigation Drawer
- **หัวข้อหลัก**: ไอคอนบ้านสีแดง outline พร้อมข้อความ "จองหอพัก", "มหาวิทยาลัยราชภัฏสงขลา (SKRU)" และ "เลือกหอพัก"
- **การ์ดข้อมูลหอพักครบถ้วนตาม Figma**:
  1. **หอพักหญิง ปาริฉัตร**: 2 คน/ห้อง • 4 ชั้น 52 ห้องพัก • ค่าบำรุง 5,700 บาท (ฟรีค่าไฟ)
  2. **หอพักชาย สบัดงา**: 2 คน/ห้อง • 4 ชั้น 34 ห้องพัก • ค่าบำรุง 5,700 บาท (ค่าไฟ 5 บาท/หน่วย)
  3. **หอพักหญิง พัฒนันรี**: 3 คน/ห้อง • 4 ชั้น 60 ห้องพัก • ค่าบำรุง 6,200 บาท (ห้องน้ำในตัว)
- **Footer แบนเนอร์สีแดง**: "สอบถามเพิ่มเติม - งานหอพัก มหาวิทยาลัยราชภัฏสงขลา"

---

### ⚡ 2. ระบบทำงานจริง (Interactive Full-Stack Flow)
- **ระบบเลือกชั้น/ห้อง/เตียง (Interactive Bed Selector Grid)**:
  - สามารถกดเลือกชั้น (ชั้น 1 - 4)
  - เลือกห้องและเลือกเตียง (เตียง A, เตียง B) ที่ยังว่างได้แบบ Real-time
  - ป้องกันการจองเตียงที่ถูกจองแล้ว (Disabled Bed)
- **ฟอร์มกรอกข้อมูลนักศึกษา (Student Registration Wizard)**:
  - คำนำหน้าชื่อ, ชื่อ-นามสกุล, รหัสนักศึกษา 11 หลัก, คณะ, สาขาวิชา, เบอร์โทรศัพท์, อีเมล
  - มีการตรวจสอบความถูกต้องของข้อมูล (Validation)
- **ใบยืนยันการจองหอพักพร้อม QR Code (Printable Booking Slip & Receipt)**:
  - สร้างรหัสการจองอัตโนมัติ (e.g. `BK47065670`)
  - พร้อม QR Code สำหรับสแกนตรวจสอบสถานะ และปุ่มพิมพ์ใบจอง (`window.print()`)
- **ระบบค้นหาการจอง (Search & Check Status)**:
  - นักศึกษาสามารถค้นหาการจองย้อนหลังด้วย **รหัสนักศึกษา** หรือ **รหัสการจอง**
  - สามารถยกเลิกการจองเพื่อคืนเตียงว่างกลับเข้าสู่ระบบได้
- **ระบบจัดการสำหรับเจ้าหน้าที่ (Admin Dashboard)**:
  - ตารางแสดงรายการจองทั้งหมด พร้อมสถานะและปุ่มยกเลิกการจอง

## 🚀 วิธีการติดตั้งและเปิดใช้งาน (Setup & Run Instructions)

### 1. การเปิดใช้งานเซิร์ฟเวอร์ Backend (Node.js)
```bash
# ติดตั้ง dependencies (หากยังไม่ได้ติดตั้ง)
npm install

# รันเซิร์ฟเวอร์ (เปิดที่ http://localhost:3000)
node server.js
```

### 2. การเข้าใช้งานผ่าน Browser
- **Frontend App**: [http://localhost:3000](http://localhost:3000)
- **REST API Endpoints**:
  - `GET /api/dorms` - รายการหอพักและจำนวนเตียงว่าง
  - `GET /api/dorms/:id` - ข้อมูลห้องพักและเตียงในหอพัก
  - `POST /api/bookings` - ส่งข้อมูลทำการจองหอพัก
  - `GET /api/bookings/search?studentId=...` - ค้นหาการจอง
  - `DELETE /api/bookings/:id` - ยกเลิกการจอง
