# ระบบกิจกรรมนักศึกษา (Student Activity Booking System)
ระบบหน้าจองกิจกรรมนักศึกษา ถอดแบบดีไซน์จาก FIGMA พร้อมระบบ Frontend (HTML/CSS/Vanilla JS) และ Backend (Node.js & Express REST API)

---

## 📱 จุดเด่นและฟีเจอร์ของระบบ
1. **ดีไซน์ถอดแบบจาก Figma แบบ Pixel-Perfect**:
   - แถบสถานะสีแดงด้านบน (Accent Red Top Bar)
   - ส่วนหัวระบบ (Header) พร้อมปุ่มย้อนกลับ `<` และข้อความ "กิจกรรม / ระบบกิจกรรมนักศึกษา"
   - การ์ดหลัก (Hero Banner Card) สีเทา Slate พร้อมลวดลายเรขาคณิต (Geometric Arcs) และเส้นขีดสีแดง
   - เมนูกลุ่มที่ 1 **"กิจกรรม"**:
     - 🔍 **ค้นหากิจกรรม** (ค้นหากิจกรรมที่เปิดให้เข้าร่วม)
     - ➕ **เพิ่มรหัสกิจกรรม** (เพิ่มกิจกรรมด้วยรหัสกิจกรรม)
   - เมนูกลุ่มที่ 2 **"ข้อมูลนักศึกษา"**:
     - 📄 **กิจกรรมที่ลงทะเบียน** (ดูรายการกิจกรรมที่ลงทะเบียนไว้ / บัตร E-Ticket)
     - ⏱️ **ตรวจสอบชั่วโมงกิจกรรม** (ตรวจสอบจำนวนชั่วโมงที่เข้าร่วม / เกณฑ์ 50 ชม.)
     - 🏛️ **ตรวจคะแนนความประพฤติ** (ตรวจสอบคะแนนและข้อมูลความประพฤติ 100/100)
     - 🛡️ **กิจกรรม กยศ.** (ข้อมูลกิจกรรมสำหรับผู้กู้ยืม กยศ. 24/36 ชม.)
   - แถบเมนูด้านล่าง (Bottom Navigation Bar):
     - หน้าหลัก, กิจกรรม (Active Red Pill), แจ้งเตือน, โปรไฟล์

2. **ระบบการทำงานเบื้องหลัง (Full-Stack Features)**:
   - **ค้นหาและจองกิจกรรม (Browse & Book)**: ค้นหาตามชื่อ/สถานที่, กรองตามหมวดหมู่ (กิจกรรมบังคับ, กยศ., วิชาการ, กีฬา, ศิลปวัฒนธรรม), แถบแสดงที่นั่งคงเหลือ และกดลงทะเบียนได้ทันที
   - **ลงทะเบียนด้วยรหัส (Activity Code Registration)**: รองรับการกรอกรหัสกิจกรรม เช่น `VOL-201`, `TECH-301`, `KYS-501` พร้อมปุ่มเลือกทดสอบรวดเร็ว
   - **บัตรเข้าร่วมกิจกรรม E-Ticket**: แสดงบัตรกิจกรรมพร้อม QR Code, เลขที่นั่ง (เช่น `A-042`), ข้อมูลนักศึกษา และบาร์โค้ด
   - **ระบบยกเลิกการลงทะเบียน**: สามารถยกเลิกกิจกรรมที่ลงทะเบียนไว้ และคืนที่นั่งให้กับระบบอัตโนมัติ
   - **ฐานข้อมูล JSON แบบ Persistence**: ข้อมูลกิจกรรมและการจองบันทึกในไฟล์ `data/activities.json` และ `data/bookings.json`

## 📂 โครงสร้างโฟลเดอร์โปรเจกต์
```

    ├── css/
    │   └── style.css    # สไตล์ CSS และการจัดวาง Responsive Layout
    └── js/
        ├── api.js       # ตัวเชื่อมต่อ API ระหว่าง Frontend กับ Backend
        └── app.js       # ควบคุมการทำงานของหน้าเว็บ, Modals, ตัวกรอง, การจอง
```

## 🛠️ รายการ REST API Endpoints
- `GET /api/activities` - ดึงรายการกิจกรรมทั้งหมด (รองรับ `?q=` ค้นหา และ `?category=`)
- `GET /api/activities/:id` - ดึงข้อมูลรายละเอียดกิจกรรม
- `POST /api/activities/book` - จองกิจกรรม `{ activityId, studentId, studentName }`
- `POST /api/activities/code` - ลงทะเบียนด้วยรหัสกิจกรรม `{ code, studentId, studentName }`
- `GET /api/my-bookings` - ดูรายการกิจกรรมที่ลงทะเบียนไว้
- `DELETE /api/bookings/:id` - ยกเลิกการจองกิจกรรม
- `GET /api/student-stats` - สรุปชั่วโมงกิจกรรม, คะแนนความประพฤติ, และชั่วโมง กยศ.
- `GET /api/notifications` - รายการแจ้งเตือนของนักศึกษา
